### 📌 Featured Projects

**[Social Posts REST API](https://github.com/Shami0/poo)**
An Express + TypeScript API with 13 endpoints for short public posts: user accounts, login with access and refresh tokens, a 140-character limit with word filtering, request metrics, and a Vitest test suite.
`Express` `TypeScript` `PostgreSQL` `Drizzle ORM` `Vitest`

**[Life Experience Tracker API](https://github.com/Shami0/life-exp)** *(in progress)*
A modular-monolith backend for daily tasks with a GitHub-style history. Tasks are separated from per-date occurrences so past days stay frozen. Includes Argon2 password hashing, rotating refresh tokens, recurring tasks, and timezone-aware dates.
`Fastify` `TypeScript` `PostgreSQL` `Drizzle ORM` `Zod` `Docker`
